# Full Evaluation Plan (side_channel_full, P1-P20)

This plan covers full-only evaluation for the side-channel benchmarks generated by
`side_channel_full.py`. It includes dataset generation, derivation-graph-only timing,
ProbLog vs Souffle (no rewrite vs rewrite), WMC scaling, and end-to-end comparisons.

## Scope
- Full computation only; no incremental modes.
- Compile with `--full-only` so reordering strategy stays consistent (default CUDD sift).
- Cover P1-P20 from SMT sources in `side_channel_benchmark/data/smt`.
- Always enable `--det-opt` for all Souffle runs (deterministic-first derivation gating).
- Avoid `--merge-bi-imp` unless explicitly testing eqrel; keep comparisons focused
  on rewrite/split behavior.
- When comparing rewrite vs no-rewrite, record the split mode (`--split-mode=...`);
  default is `naive-split`.
- CUDD init uses a bucketed scheme for small/medium graphs and the original
  defaults for large graphs; `rand_vars` is the count of probabilistic facts
  plus probabilistic edges in the pruned view used for forward compilation.

## Prerequisites
- Build release Souffle and the precompiled runtime library (required if runtime
  headers changed):
  ```bash
  cmake --build cmake-build-release --target compiled -j4
  cmake --build cmake-build-release --target souffle -j4
  ```
- Put the release binary on PATH:
  ```bash
  export PATH="/home/hugh/research/datalog/souffle/cmake-build-release/src:$PATH"
  ```
- ProbLog on PATH (for baseline and grounding-only).
- Use time limits for ProbLog runs (some cases do not finish).

## Full rule set evaluation (2026-01-05, det-opt + component-wise FC)
Settings:
- Rule set: `full` (generated by `side_channel_full.py`), base dir
  `experiments/side_channel_full_eval`.
- Compile: `--full-only` (release binary on PATH).
- Run: `./compute --det-opt` vs `./compute --det-opt --rewrite`.
- Split mode: default `naive-split` (rewrite only).
- Backend: BDD (CUDD).
- Rewrite uses component-wise FC + WMC inside `FC_WMC_HYBRID`, and the stage now
  starts before rewrite so its wall time includes rewrite + split overhead.
- BDD manager init is lazy: it is created only when slow components exist.

Notes:
- `rand_vars` counts probabilistic facts + probabilistic edges in the pruned view
  used for forward compilation (after rewrite if enabled).
- `rewrite_s` comes from `rewrite_ms` recorded inside `FC_WMC_HYBRID` (SISO
  detect/rewrite + split).
- Both pipelines now store probabilities only for `needOutput` nodes; no-rewrite
  also applies evidence per component. This keeps `IO_DUMP` comparable between
  rewrite and no-rewrite.
- `manager_init_ms` is reported in the stage where init happens (no-rewrite FC
  or rewrite hybrid); it is `0` when no slow components exist.
- `hybrid_s` is the wall time of `FC_WMC_HYBRID` (rewrite only) and now includes
  rewrite + component FC/WMC.
- For rewrite, `fc_s`/`wmc_s` are derived from `fc_build_ms` and `wmc_ms` recorded
  in the hybrid stage.
- `FORWARD_COMPILATION_FULL` appears only in no-rewrite runs.
- `dd_live_nodes` for rewrite is the **sum** of per‑component live nodes; it is not
  directly comparable to the single‑manager count and may be inaccurate for
  absolute size comparisons.
- P2 is missing in the dataset and is skipped.

## Measurements

### 1) Derivation graph generation vs ProbLog grounding
Goal: isolate derivation-graph build time in Souffle and compare to ProbLog grounding.

Souffle derivation graph only:
```bash
for p in experiments/side_channel_full_eval/P{1..20}; do
  [ -x "$p/compute" ] || continue
  (cd "$p" && ./compute --derv-only -F input -D output_dg \
    --logfile log_$(basename "$p")_derv)
done
```
- Use `log_P*_derv*.json` for timing (typically just the SEM/derivation stage).
- Add `--dumpjson` / `--dumpdot` if you need graph dumps.

ProbLog grounding only (use a timeout; large cases may not finish):
```bash
for p in experiments/side_channel_full_eval/P{1..20}; do
  [ -f "$p/compute.problog.dl" ] || continue
  (cd "$p" && timeout 600 problog --ground compute.problog.dl \
    > output_dg/problog.ground.out 2>&1)
done
```
- Record wall-clock time; treat timeouts as upper bounds.

### 2) ProbLog vs Souffle no-rewrite vs rewrite
Compare three variants: ProbLog baseline, Souffle full without rewrite, and Souffle
full with rewrite. Avoid `--merge-bi-imp` unless explicitly testing eqrel.

Manual run (keeps outputs separate):
```bash
for p in experiments/side_channel_full_eval/P{1..20}; do
  [ -x "$p/compute" ] || continue
  (cd "$p" && ./compute --det-opt -F input -D output_norewrite \
    --logfile log_$(basename "$p")_norewrite)
  (cd "$p" && ./compute --det-opt --rewrite -F input -D output_rewrite \
    --logfile log_$(basename "$p")_rewrite)
done
```
