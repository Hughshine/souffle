# Process Documentation

This folder contains workflow and hygiene docs for contributors and maintainers.

## Contents
- `docs/process/README.git.md`: commit hygiene and message conventions.
- See `docs/research/README.protocol.md` for experiment provenance and validity
  rules; it complements process docs rather than replacing them.

## Usage
- Keep process rules here, not in technical module docs.
- Reference these docs from `README.md`, `CONTRIBUTING.md`, and `AGENTS.md`.
- Distill stable experiment conclusions into `docs/research/*` instead of
  leaving them only in local run directories.
